## 🚀 Мои главные проекты

### 🎚️ [VolKey](https://github.com/Xyberov/VolKey)
Утилита для Windows 10/11 на C# (.NET 10): управление музыкой жестами на клавишах громкости.
* `Vol+ → Vol− → Vol+` — следующий трек, свои комбинации можно записать прямо с клавиш.
* Живёт в трее, показывает плашку с треком и обложкой, не мешает в полноэкранных играх.
* Светлая/тёмная тема, русский и английский интерфейс, установщик и portable-версия, релизы через GitHub Actions.

### 🔐 [CaesarSharp](https://github.com/Xyberov/CaesarSharp)
Десктопная утилита на C# для шифрования и автоматического криптоанализа шифра Цезаря.
* Поддерживает **13 языков** и умеет взламывать текст частотным анализом.
* Имеет два интерфейса под одним капотом: современный **WinUI 3 GUI** и автоматизированный **CLI**.

### 🎮 [Dungeon Fragments](https://github.com/Xyberov/Dungeon-Fragments)
**2D top-down action RPG dungeon crawler** на Unity, вдохновлённый *Minecraft Dungeons*.
* Стабильный релиз v1.0.0, полноценная боевая система, рывки и лечение.
* Создано с нуля. Доступно на itch.io!
